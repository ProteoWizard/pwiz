CarafeSharp command-line usage

CarafeSharp - spectral library prediction and fine-tuning for Osprey (C# port of Carafe)

USAGE: CarafeSharp --build-entrapment-fasta <out.fasta> --db <proteins.fasta> [options]

CarafeSharp --reconcile-manifest <out.tsv> --manifest <in.tsv> --predicted-library <library.tsv|.blib>

CarafeSharp --db <peptides.fasta|proteins.fasta> --o <folder> [options] (library prediction)

CarafeSharp --i <osprey.blib> --ms <runs> --o <folder> [--db <fasta>] [options] (training)

CarafeSharp --i <run.training.parquet|folder> [--ms <runs>] --o <folder> [--db <fasta>] [options]

CarafeSharp --model-info <file.model.zip>

Modes and files
ArgumentDescription
--build-entrapment-fasta <out.fasta>Build the peptide FASTA a library is predicted from: the digest of the proteins of --db, with decoys and, with --entrapment, entrapment peptides; the pairing manifest goes to --manifest.
--reconcile-manifest <out.tsv>Write the pairing manifest of --manifest reconciled against the predicted library of --predicted-library, dropping the pairs the library did not keep whole.
--manifest <manifest.tsv>The pairing manifest: written by --build-entrapment-fasta, read by --reconcile-manifest.
--predicted-library <library.tsv|.blib>The predicted library (a TSV, or a .blib) a manifest is reconciled against.
--model-info <file.model.zip>Describe a saved model (.model.zip, a ZIP archive): what it was trained on, and how.
--db <proteins.fasta|peptides.fasta>The FASTA to predict a library from (peptides, as --build-entrapment-fasta writes them, or proteins), or the proteins --build-entrapment-fasta digests. With training (--i), the library predicted with the fine-tuned models afterwards.
--i <osprey.blib|run.training.parquet|folder>Osprey's results to train on: its .blib with --ms, or its training exports (one run's .training.parquet, a comma-separated list of them, or a folder of them) with or without --ms. With a .blib and no --ms a library is predicted instead, as in Carafe.
--ms <run1,run2,...>The runs trained on, comma-separated. CarafeSharp reads no spectra: the fragment matches, XICs and peak boundaries come from Osprey's training export, so --ms only names the runs.
--o <folder>The output folder: the library, and for training the fine-tuned model folder and the saved .model.zip.
-h, --help [<format|Section>]Print this usage and exit. An optional value picks the form: ascii or unicode (the default) tables, sections (the section names only), html, or a section name for that section alone.
Digest and modifications
ArgumentDescription
--enzyme <index|NoCut>The enzyme, by Carafe's index (default 1, trypsin), or NoCut for the non-specific digest, which forces 100 missed cleavages.
--miss-c <n>Maximum missed cleavages (default 2).
--minLength <n>Minimum peptide length (default 7).
--maxLength <n>Maximum peptide length (default 35).
--clip-n-mAlso digest each protein with its N-terminal methionine removed.
--fixMod <ids>Fixed modifications, Carafe's ids comma-separated (default 1, carbamidomethyl C).
--varMod <ids>Variable modifications, Carafe's ids comma-separated (default 2, oxidation M).
--maxVar <n>Maximum variable modifications per peptide (default 1).
--min-pep-mz <mz>Minimum precursor m/z (default 300).
--max-pep-mz <mz>Maximum precursor m/z (default 2000).
--min-pep-charge <z>Minimum precursor charge (default 2).
--max-pep-charge <z>Maximum precursor charge (default 3 for the FASTA build, 4 for library prediction).
--I2LConvert isoleucine to leucine in every sequence.
Entrapment FASTA build
ArgumentDescription
--entrapmentAdd entrapment peptides, shuffled from the targets, or taken from the proteins of --entrapment-db.
--no-decoysWrite no decoy peptides.
--decoy-prefix <prefix>The prefix of decoy protein names (default decoy_ for the FASTA build, rev_ for a library).
--mz-filterKeep only the peptides with a precursor m/z inside --min-pep-mz to --max-pep-mz at some charge of --min-pep-charge to --max-pep-charge, modifications counted.
--entrapment-seed <n>The seed of the entrapment shuffle (default 42).
--decoy-seed <n>The seed of the decoy generation (default 24).
--entrapment-db <proteins.fasta>A FASTA of a foreign species whose peptides are the entrapment, in place of shuffled targets.
--entrapment-ratio <ratio>Entrapment peptides per target, 0.1 to 1.0 (default 1.0).
--no-similarity-gateKeep the entrapment peptides that are near-copies of their own targets. For audit comparison only: the resulting library should not be searched.
--ignore-pairing-errorsWrite the pairing manifest even when it fails its integrity checks.
Library prediction
ArgumentDescription
--lf-type <DIA-NN|EncyclopeDIA|Skyline|blib>The library format, comma-separated for more than one: DIA-NN (default), EncyclopeDIA or Skyline, a TSV in that notation, or blib, a BiblioSpec library. Skyline with --fast writes a .blib too.
--fastWith --lf-type Skyline, write the library as a .blib; without --fast Carafe writes a generic TSV.
--lf-frag-mz-min <mz>Minimum fragment m/z (default 200).
--lf-frag-mz-max <mz>Maximum fragment m/z (default 1800).
--lf-top-n-frag <n>Fragments kept per precursor, the most intense first (default 20).
--lf-min-n-frag <n>Minimum fragments for a precursor to be written (default 2).
--lf-frag-n-min <n>Lowest fragment ordinal kept, b and y alike (default 2).
--nce <nce>The normalized collision energy the MS2 model predicts at (default 27, or a model folder's).
--ms-instrument <name>The instrument the MS2 model predicts for, by AlphaPeptDeep's name (default Eclipse, or a model folder's).
--activation <beam-CID | reCID>The activation predicted for, else a training run's. Not in Java Carafe.
--analyzer <Orbitrap | LIT | ToF>The MS2 analyzer predicted for, else a training run's. Not in Java Carafe.
--rt-max <minutes>The gradient length the library's retention times are scaled to, in minutes; absent, iRT.
--ccsPredict ion mobility (1/K0) for timsTOF.
--pairing-manifest <manifest.tsv>The pairing manifest of --build-entrapment-fasta: the library then carries Carafe's DecoyPairs table, every pair written whole or not at all.
--library-contractCheck the library against the Osprey library contract (one row per precursor, clean accessions, decoys and entrapment marked, the manifest authoritative, pairs whole) before predicting and after writing, refuse or discard it on a violation, and mark the .blib as meeting the contract so Osprey checks it at load instead of repairing it. Needs --lf-type blib and --pairing-manifest, and a FASTA built without Carafe's per-peptide accession suffix.
--rt-reference <run>With a model trained with --rt-align kde, the training run whose minutes the library takes; else the model's, and iRT for a model of runs on different gradients. Not in Java Carafe.
Models
ArgumentDescription
--model-dir <folder>A Carafe fine-tuned model folder to predict with: its MS2 and RT models, metrics and training-run summary.
--model <file.model.zip>A saved model (.model.zip, a ZIP archive), which every training run writes into --o: predict a library with it, or with --i fine-tune it further. Not in Java Carafe.
--pretrained <pretrained_models.zip>The AlphaPeptDeep pretrained models zip (default: the one beside the executable). Not in Java Carafe.
--tf <all | ms2 | rt>The models to train, or to predict with from --model-dir: all (default), ms2 or rt.
--rt-model <alphapeptdeep | chronologer>The retention-time model (default: the one of a saved model or model folder, else chronologer). A different one from a fine-tuned model's predicts with its pretrained model, Chronologer's in iRT. Not in Java Carafe.
--device <cpu | gpu | cuda>Where the models run: cpu, or gpu / cuda (default; the CPU when there is no CUDA device).
--ms2-model <model>The MS2 model (a PyTorch checkpoint) fine-tuning starts from, in place of the pretrained one.
Training
ArgumentDescription
--se <Osprey>The search engine of --i: only Osprey, whose training export CarafeSharp trains on.
--fdr <q>The q-value cutoff of the precursors trained on (default 0.01).
--cor <r>The minimum fragment correlation of a precursor trained on (default 0.75).
--n-ion-min <n>The lowest b-ion ordinal trained on (default 0, every ordinal).
--c-ion-min <n>The lowest y-ion ordinal trained on (default 0, every ordinal).
--nf <n>The minimum matched fragments of a precursor trained on (default 4).
--min-n <n>The minimum valid fragments of a precursor trained on (default 4).
--validRequire a precursor's most intense fragment to be valid.
--no-maskingTrain on every ion of the kept spectra, masking none.
--seed <n>The random seed of training (default 2024; not negative).
--rt-align <none | kde>How the training runs' retention times are aligned before the RT model is fine-tuned: kde (default; each run's minutes mapped onto Chronologer's hydrophobic index by a KDE ridge on 1000 peptide forms or more, else a LOESS or a line; runs on one gradient train a model of their aligned minutes, runs on different gradients a Chronologer of the index) or none (Carafe's one rt_max). Not in Java Carafe.
--rt-select <best | median>With aligned runs, the retention time a peptide form trains on: its best run, or the runs' median. Not in Java Carafe.
Output
ArgumentDescription
--log-file <path>Write every line of output and error to this file instead of the console. Not in Java Carafe; any mode.
--timestampPrefix each line with the time. Not in Java Carafe.
--memstampPrefix each line with the managed and private memory in use. Not in Java Carafe.
Carafe options accepted for compatibility

Carafe 2.2.0 options these modes do not read. Each is accepted so a Carafe command line runs unchanged; one that CarafeSharp cannot honor is refused, and the rest are ignored, as Carafe ignores them.

ArgumentDescription
--itol <tolerance>Carafe's XIC extraction settings (--itol, --itolu, --sg, --min-mz, --rf, --rf-rt-win, --rt-win-offset) are Osprey's to decide: the matches, XICs and peak boundaries come from its training export, so each is reported and ignored.
--itolu <unit>See --itol.
--sg <n>See --itol.
--na <n>Flanking spectra; only 0 is supported.
--ptm-site-prob <p>Accepted for Carafe compatibility; not used by CarafeSharp.
--ptm-site-qvalue <q>Accepted for Carafe compatibility; not used by CarafeSharp.
--min-mz <mz>See --itol.
--lf-format <format>Carafe's library file format; parquet is not supported.
--rf-rt-win <window>See --itol.
--rt-win-offset <minutes>See --itol.
--data-type <type>Accepted for Carafe compatibility; not used by CarafeSharp.
--build-koina-library <out>Not supported by CarafeSharp, which has no Koina client.
--koina-url <url>Accepted for Carafe compatibility; not used by CarafeSharp.
--koina-ms2-model <name>Accepted for Carafe compatibility; not used by CarafeSharp.
--koina-rt-model <name>Accepted for Carafe compatibility; not used by CarafeSharp.
--nce-ms <nce>Accepted for Carafe compatibility; not used by CarafeSharp.
--mode <mode>Carafe's mode; only general is supported.
--python <path>Accepted for Carafe compatibility; not used by CarafeSharp.
--mod2mass <mapping>Not supported by CarafeSharp.
--user-var-mods <mods>Not supported by CarafeSharp.
--verbose <level>Accepted for Carafe compatibility; not used by CarafeSharp.
--ai-version <version>Carafe's Python version; only v2 is ported.
--printPTMNot supported by CarafeSharp.
--nmAccepted for Carafe compatibility; not used by CarafeSharp.
--csNot supported by CarafeSharp training.
--ezA Carafe diagnostic file (--ez, --xic, --export-mgf, --skyline) CarafeSharp does not write; reported and ignored.
--skylineSee --ez.
--use-all-peaksNot supported by CarafeSharp training.
--rfSee --itol.
--xicSee --ez.
--export-mgfSee --ez.
--y1Not supported by CarafeSharp training.
--torch-compileAccepted for Carafe compatibility; not used by CarafeSharp.

OTHER FORMS ACCEPTED: the options are listed in the standard form (--lf-type blib). A value may follow its option or be joined to it (--lf-type=blib), and for compatibility with Java Carafe every option is also accepted in Carafe's form, with a single dash and underscores (-lf_type blib, -lf_type=blib), so a Carafe 2.2.0 command line runs unchanged. A repeated option keeps its first value, as in Carafe.
